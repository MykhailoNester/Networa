Import your portfolio from plain CSV files. See docs/import-format.md for the full column reference. Import the Assets CSV first (creates assets and sheets), then the Cashflows CSV so entries can be linked to existing assets by name.

Assets CSV

Import assets and debts. Values in any currency are converted to USD. Sheets are auto-created when new.

Click to select CSV file

Columns: name (required), asset_class (required: real_estate, precious_metal, cash, stock, fund, crypto, vehicle, investment, miscellaneous), value (required, number), currency (ISO 4217, default USD), category (asset|debt, default asset), sheet, section, ticker, quantity, price, cost_basis, cost_basis_currency, notes.

Cashflows CSV

Import transaction history. Entries are linked to existing assets by name.

Click to select CSV file

Columns: date (required, YYYY-MM-DD), asset (matched by name), cash_in / cash_out (bare number or "USD 65.25"), currency (default USD), description, notes, status (default Active).

Import order: Import the Assets CSV first (creates assets and sheets), then import the Cashflows CSV (links entries to existing assets by name).
